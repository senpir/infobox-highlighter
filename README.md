# InfoBox Highlighter

A RuneLite plugin that allows individual infoboxes to be highlighted with customizable colored outlines.

## Features

- Shift + right-click an infobox to set a highlight
- Uses RuneLite's native color picker
- Different infoboxes can use different highlight colors
- Remove highlights directly from the infobox context menu
- Configurable outline width
- Configurable outline feathering
- Highlights stay attached to detached and repositioned infoboxes


## Usage

Hold **Shift** and right-click an infobox, then select **Set highlight**.

Choose a color.

Outline width and feathering can be adjusted from the **InfoBox Highlighter** plugin settings.

To remove a highlight, Shift + right-click the infobox and select **Remove highlight**.

***Flash update***
- Set a separate flash color for timed infoboxes
- Configurable timer threshold for when flashing begins
- Configurable flash intensity
- Flash color overrides the normal highlight while active
- Pulsing feather effect draws attention to expiring timers
